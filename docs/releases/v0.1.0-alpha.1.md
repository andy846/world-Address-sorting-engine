# v0.1.0-alpha.1 - TEST ONLY Developer Preview (NOT FOR PRODUCTION)

**Release type:** GitHub pre-release for developers and internal testers.
**Source:** `feat/hkp-trilingual-phase1`; this release is not merged into
`main` and does not replace `v0.1.0-alpha.0`.

## TEST ONLY

This build must not be used to classify, print, insert or dispatch live
mail. It does not contain the verified Hongkong Post two-character
destination master. Its Hongkong Post catalogue is a synthetic test fixture
with no official standing.

The release is a developer preview, not a production release. Production
readiness remains blocked by the missing official Hongkong Post master,
incomplete 1M/5M acceptance measurements and clean offline Windows
operator acceptance.

## Included

- Python wheel for Python 3.12 and later.
- Windows one-file GUI executable built and self-tested by the
  release workflow.
- Conservative offline classification improvements for nested country names,
  company/brand text, Unicode word boundaries, Han administrative suffixes
  and same-spelled localities.
- Bounded geographic occurrence processing, mandatory checkpoint shard
  verification and safer benchmark ownership/provenance.
- SHA-256 checksums for every application asset.

## Not included

- No GeoNames database pack is attached to this application release.
- No official Hongkong Post master, customer address, plaintext checkpoint
  or production approval key is included.
- No production-readiness claim is made.

## Verification

The release workflow runs the complete Linux regression suite, installs and
verifies both k2 GeoNames packs for slow offline checks, builds the wheel and
tests an installed-wheel smoke path. A separate Windows job builds the GUI
executable and requires its packaged self-test to pass. Publication happens
only after both jobs succeed.

For publication from the development branch, the push must include the
release-notes/workflow path and the exact commit subject
`chore(release): publish v0.1.0-alpha.1 [publish-alpha1]`. The workflow checks
the full branch ref, preserves the existing alpha.0 identity, and verifies
downloads against the pre-upload checksum manifest. A failed or cancelled
publication is returned to an unpublished draft by its recorded release ID
when the GitHub API remains available. The marker records publication intent;
it is not an independent reviewer approval. Repository-wide release
immutability and independent required reviewers are not configured.

Local verification before publication: 694 passed, 1 skipped, 2 expected
failures with both real k2 packs and slow checks, plus successful syntax
compilation (115.52 seconds for the suite). Release-workflow regression
tests cover the publication fixes; the final CI run is the release evidence.
Independent classification review approved the exact regression assertions
with no remaining P0/P1/P2 findings in that reviewed scope.

Measured synthetic end-to-end pipeline at clean commit `ec5301c`, rules
`2026-10-23.5`: 2,000 rows in 18.651 seconds (107.2 records/sec, 47.8 MiB
peak RSS); 100,000 rows in 911.675 seconds (109.7 records/sec, 56.8 MiB peak
RSS). All 100,000 rows reconcile: 96,364 MATCHED and 3,636 REVIEW_AMBIGUOUS.
The checkpoint occupied 62,057,316 bytes; exported files 25,944,558 bytes.
No 1M/5M performance result is claimed.

The locally validated onefile executable was 48,488,511 bytes (46.24 MiB).
The release workflow rebuilds it; use the attached checksum for the actual
published binary. Wheel and EXE are unsigned. Python 3.13 is the tested
runtime; 3.12 is the declared minimum and has no separate runtime result.

Known accuracy limitation: the k2 packs lack `香港特别行政区` in Simplified
Chinese. `中华人民共和国香港特别行政区` currently resolves to CN rather
than HK; an expected-failure regression exists for each profile. This needs
a future pack rebuild and is a production acceptance blocker.

## Install

```powershell
python -m pip install .\world_address_sorting_engine-0.1.0a1-py3-none-any.whl
python -m pip install "openpyxl>=3.1,<4"
```

`--test-only` acknowledgement. Protect local `.job-state` checkpoints because
they contain plaintext input rows.

operations.**
