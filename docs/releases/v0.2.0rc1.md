# v0.2.0rc1 — local Hong Kong regional-pack candidate

Status: local candidate, not published. v0.1.0 remains the formal release and
GitHub Latest. No existing release assets, tags or pull requests are replaced.

This candidate adds an optional, separate ALS bilingual address pack. Official
English and Traditional Chinese names share address identities; derived
Simplified aliases retain provenance. Eligible unresolved estimates can become
`INFERRED HK` when independent address components agree on the same record.
Existing country assignments and explicit geographic conflicts are preserved.
Air/surface services and postal prices remain outside country-code analysis.

The GUI adds an optional pack switch, file selector, verification stage and
actual version display, including paused/cancelled results. CLI selection,
offline installation and checkpoint recovery pin DB and manifest hashes.
The pack is not embedded in the EXE and no lookup API is used.

Validation completed so far:

- Original 9,604-row private replay with regional option disabled: 7,143
  determined, 2,419 inferred, 42 unresolved. All three report files are
  byte-identical to the reviewed v0.1.0 baseline.
- Independent registry/job, matcher, builder and GUI reviews produced targeted
  negative regressions. The implementation ledger records RED/GREEN evidence
  and final integrated results.
- Final local full regression with real k2 packs and slow checks: 1,487 passed,
  1 skipped, 2 pre-existing xfails in 224.25 seconds.
- Regional-disabled repeated million: 158.456 seconds, 6,310.89 rows/second,
  74,280,960-byte peak RSS. Cancel at 500,000 and fresh-process resume passed
  exhaustive verification; all CSVs and manifests match the full run exactly.
- Actual Windows one-file build passed its offline synthetic self-test,
  including selected regional path, positive matching, contradictory number
  rejection, completed output and version display.

Local EXE: 48,760,746 bytes. SHA256:
