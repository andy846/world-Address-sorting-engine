## Included

- Automatic discovery of installed global Extended (Compact fallback) and HK
  packs. HK starts enabled; select an installed pack or explicitly turn it off.
  Verification runs in the background and retains partial-source disclosure.
- Fresh GUI batches create timestamped output folders beside the input.
  Custom locations select a parent; collisions get suffixes. Resume retains
  its original folder and pinned sources. CLI output remains an exact folder.
- A separate multi-line quick lookup page, Ctrl+Enter, clear/copy and country,
  status, Zone/NOVSN display. Queries work during batch processing; complete
  address cache keys are discarded and edits invalidate stale results.
- Literal audited mappings for all 235 active business country codes. CN is
  `CN - Airmail` / F, HK LOCAL / A, MO `Macau - Surface` / M, TW Taiwan / F.
  No mail-service inference or rate calculation is introduced.
- Schema2 detail/summary/case exports, mapping identity pins and state3 resume.
  Original fields/order are preserved. Unknown records leave generated fields
  blank. Legacy completed reports remain read-only with blank zones; state2
  interrupted runs require v0.2.0. System/Light/Dark themes remain available.

## Install offline

Download `WorldAddressEngine.exe` and `SHA256SUMS.txt` from this release and
verify its hash. The EXE does not embed reference databases.

- [Global GeoNames k2 packs](https://github.com/andy846/world-Address-sorting-engine/releases/tag/geonames-packs-2026-10-22-k2):
  Compact 142,577,664 bytes or Extended 1,087,344,640 bytes.
- [HK ALS partial-source TEST pack](https://github.com/andy846/world-Address-sorting-engine/releases/tag/hk-als-partial-2026-10-23-r1):
  747,376,640-byte SQLite, 173,215 addresses and 9,508 excluded features.
  Keep its manifest, audit, quarantine and attribution together.
- Place installed packs under the application's `packs` folder or use manual
  reference selectors. Select an input and its address columns, then analyze.
  Leave Output parent blank for an automatic sibling output folder.
- Single address lookup queries locally and saves no address history.

Reference data keep their original terms/attribution. Hong Kong coverage remains
partial-source TEST. Broader labelled accuracy, million-distinct/5M workloads,
clean disconnected installation and strict-postal approval remain separate
scopes; no global production-readiness or deliverability claim is made.
