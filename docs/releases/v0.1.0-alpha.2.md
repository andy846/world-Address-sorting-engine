# v0.1.0-alpha.2 - Country Code analysis developer preview

Default purpose: address -> Country Code -> counts by code. No air/surface,
rate, Zone or Novsn decisions. Mainland China is `CN`, never service-only `CNS`.

## Changes

- Bundled USER_PROVIDED reference profile: 235 geographic entries, 236 audited
  source rows, bilingual names, source pages and PDF SHA-256. Runtime needs no
  PDF parser or network. Kosovo geographic XK maps to source XO; source XK
  remains Caroline Islands. This profile is not an approved production HKP master.
- Practical, explainable estimates from country aliases, contextual HK/KLN
  abbreviations, Hong Kong localities, mainland administrative regions and
  substantial single-city leaders. Recipient/company lines, street names and
  competing destinations are handled separately.
- Default Country Code GUI, `analyze` CLI and resumable CSV/TXT/XLSX jobs.
  Originals/order/duplicate rows are preserved, summary counts reconcile,
  diagnostics distinguish DETERMINED, INFERRED and UNRESOLVED, and the manifest
  is published last. Failed manifest publication can recover without retaining
  plaintext row shards.
- Packaged OpenCC 0.1.7 data provides the same offline normalization used in
  source validation. The onefile self-test checks the new GUI, all 235 entries
  and a complete synthetic country-analysis output, as well as the legacy
  strict approval-refusal checks.
- Cooperative preview cancellation stops large input scans and closes the
  source reader instead of reporting incomplete counts as a completed preview.

## Measured local validation

A local 9,604-record supplied file contained no empty addresses or decoding
errors. The old engine diagnostic with Extended k2 and a 36-destination test
postal catalogue left 3,795 UNKNOWN/Review rows (39.52%). That diagnostic is
not the unavailable original run configuration or an accuracy-labelled dataset.

The new country-analysis output has 7,120 DETERMINED, 2,322 INFERRED and 162
UNRESOLVED rows: 9,442 codes, 98.31% coverage, 1.69% unresolved. Counts reconcile
to 9,604. Inference alone measured 17.489 seconds and 51,146,752 peak RSS bytes;
the full job, verified exports and cleanup measured 40.811 seconds and
55,025,664 peak RSS bytes. Final output files total 1,578,314 bytes. These are
measured Windows/Python 3.13.2 results, not a throughput promise on other PCs.

The raw input, per-row outputs and recipient information remain local and are
not release assets or CI fixtures. The estimated codes have not been checked
against a fully labelled copy of that file: coverage must not be described as
98.31% accuracy. Independent code reviews used synthetic cases and found
recipient, territory, street/company and finalization defects which received
regression fixes.

Final local regression: 870 passed, 1 skipped, 2 known expected failures in
152.24 seconds with both real k2 packs and slow integrity checks enabled.
The remaining xfails belong to the unchanged strict retrieval interface.
Python syntax checks, isolated installed-wheel resource/OpenCC checks and
the actual onefile EXE self-test passed. The locally built EXE measured
48,557,449 bytes; CI-built release sizes can differ. Native Windows rendering
was inspected separately from the fontless offscreen test backend.

## Assets and use

The application release contains only the Python wheel, Windows EXE and
SHA256SUMS.txt. GeoNames packs remain in the separate
[k2 reference release](https://github.com/andy846/world-Address-sorting-engine/releases/tag/geonames-packs-2026-10-22-k2):
Compact 142,577,664 bytes; Extended 1,087,344,640 bytes.

For Python use, install the wheel and optional Excel/GUI dependencies in advance.
The EXE includes its application dependencies and country mapping, but not a
GeoNames database. Select/install a pack before taking the machine offline.

Country estimates support list inspection; they do not establish postal
deliverability or approval of a mailing. The existing strict classifier still
requires its separately signed production catalogue. Larger-volume 1M/5M and
clean offline operator acceptance remain separate work. Alpha.0 and alpha.1
are preserved unchanged.
