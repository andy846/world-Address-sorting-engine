# v0.1.0 — Verified Country Code Analysis

First operator-accepted, non-prerelease **Country Code** list-analysis release,
designated **Latest**. The operator accepted the completed local tests and
requested formal publication on 2026-10-24. Functionality is based on verified
commit `39a3d41`; release preparation changes version metadata, documentation,
metadata tests and the CI version assertion, without changing classification,
input/output, checkpoint, GUI or reference-data behavior.

## Included

- Fully offline Country Code analysis of CSV/TXT/XLSX address lists, with
  English, Traditional Chinese, Simplified Chinese and mixed-input support.
- Country summaries, preserved original fields/order/duplicate rows, detailed
  progress, cancellation/resume, authenticated exports and pending-case pages.
- Windows workbench with input sidebar, icon, completion metrics, case details
  and persistent System/Light/Dark appearance choices.
- Source-order address-column selection regardless of click order; clearer
  Excel mapping/output-folder failures and returned-mail diagnostics.
- Country rules `2026-10-24.country.4`, improved geographical context and
  conflict handling. Bounded cache retains repeated working sets using at most
  16,384 entries and 16 MiB of UTF-8 key text; total process memory is measured
  separately, not capped by this text budget.
- Bundled 235-entry country-code profile from the supplied country list.
  Mainland China is CN; service-only CNS is excluded. No air/surface, rates,
  Zone or Novsn decisions are required for this workflow.

## Accepted validation

- Original 9,604-row local input: 7,143 determined, 2,419 inferred, 42
  unresolved; code coverage 99.563%, **not labelled accuracy**. Forty unresolved
  records already state returned-mail/unknown-address, two lack context.
- Requested repeated workload: 9,604 original rows + 396 labelled public
  controls, whole block copied 100 times = **1,000,000 rows**. There are **9,606
  distinct address/hint keys**, not one million distinct addresses.
  The 396 control records are four verified public addresses, 99 copies each.
- Complete analysis, checkpointing, source verification, exports and cleanup:
  **152.847 seconds**, **6,542.49 records/second**, **73,265,152-byte peak process
  working set**. Reports total 173,100,244 bytes; peak checkpoints 856,393,211
  bytes, removed on completion.
- A second job was cancelled at 500,000 rows. A fresh-process resume completed
  in 151.896 seconds; all three CSV reports and the manifest were byte-identical
  to uninterrupted results. Every row/field/result was independently streamed
  against the one-block oracle. All 39,600 control rows matched their labels.
- Local full real-pack regression: 1,287 passed, 1 skipped, 2 existing
  strict-retrieval expected failures. Latest focused benchmark/cache/verifier
  tests: 85 passed. Independent code reviews and actual Windows EXE offline
  self-tests passed. Release-identity full local regression passed again:
  **1,289 passed, 1 skipped, 2 existing expected failures in 195.32 seconds**.
  The actual v0.1.0 Windows onefile self-test also passed. CI/build checks run
  again for the exact release commit before publication.

## Downloads and setup

Application assets: **WorldAddressEngine.exe**, the **0.1.0 Python wheel**,
and **SHA256SUMS.txt**. Verify downloaded bytes against the checksum file.
The EXE includes application dependencies and country mapping, but does not
bundle a worldwide database. Select an already installed pack, or download the
separate reviewed data release before using the application offline:

[GeoNames k2 reference packs](https://github.com/andy846/world-Address-sorting-engine/releases/tag/geonames-packs-2026-10-22-k2)

- Compact SQLite: 142,577,664 bytes (135.973 MiB).
- Extended SQLite: 1,087,344,640 bytes (1,036.973 MiB).

Choose a new empty output folder for new analysis; use Resume for a saved
incomplete run. Existing completed reports are immutable. The case interface
supports inspection/export; country correction writeback is not included.

## Scope retained for further validation

This formal release is accepted for the measured **country-list statistics**
workflow. Coverage and repeated controls do not establish global classification
accuracy. Low-duplication/million-distinct workloads, 5M processing, million-row
GUI interaction, abrupt termination/power-loss recovery and clean disconnected
Windows installation remain additional validation work.

The separate strict postal classifier still requires its signed, independently
approved official catalogue. Publishing this Country Code release does not
approve that catalogue or remove its gate. Existing alpha.0/alpha.1/alpha.2 and
data-pack releases remain unchanged. This release does not merge Draft PR #2
or advance main.
