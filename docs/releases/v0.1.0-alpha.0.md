# v0.1.0-alpha.0 — Development Preview (NOT FOR POSTAL PRODUCTION)

**Release type:** GitHub pre-release. Source: `feat/hkp-trilingual-phase1`, NOT merged into `main`.
**Python:** 3.12+ (tested locally on Linux/Python 3.13). **Audience:** developers and internal testers only.

## Included
- Conservative offline postal address processing for English, Traditional Chinese and Simplified Chinese inputs.
- Streaming CSV/TXT and read-only Excel (.xlsx) adapters, including `NAME_ADDRESS_LINE1` to `NAME_ADDRESS_LINE5`, duplicate blank headers and `Control no` values.
- HK Post 2-character destination code catalogue importer (separate from ISO and 3-character EC-Ship codes), integrity-checked GeoNames Compact/Extended SQLite **builders**.
- Privacy-safe `world-address-engine preview --input sample.csv`.
- Experimental `world-address-engine classify` and `resume` with SHA-256 source pinning, restart checkpoints, manual-review and summary reports; **test fixtures only** via explicit `--test-only`.
- Offline database build scripts and workflow definitions.

## Important: NOT a production release
- The complete authoritative current **Hongkong Post HKP_DESTINATION_2** master has **not been sourced and manually validated**. Do not classify or print live mail.
- Real full worldwide **GeoNames** Compact and Extended SQLite data packs **are NOT bundled**; full worldwide installed DB sizes are NOT yet measured/verified. Builder source archives are downloaded separately; processing itself remains offline.
- No shipping Windows GUI, packaged Windows executable, or measured million-address throughput. No independent Subagent review / Windows release qualification.
- GeoNames data is third-party and requires license/attribution compliance (GeoNames CC BY 4.0).
- The local `.job-state` folder holds **plaintext recipient addresses**; protect it with filesystem access restrictions and delete according to retention policies. Do not upload private mailing data or snapshots.

## Install / inspect (developer)
Download the attached Python wheel and run:

```powershell
python -m pip install "world_address_sorting_engine-0.1.0a0-py3-none-any.whl[excel]"
world-address-engine preview --input "sample.csv"
```

See project README for the test-only classification commands. No real customer addresses are included in release artifacts.
