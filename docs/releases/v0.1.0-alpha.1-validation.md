## Review and preservation

Independent classifier re-review approved `076cc2b` for release validation
with no P0/P1/P2 findings in that scope. Release review found draft lookup,
checksum anchoring, branch-ref and failure-recovery defects; `983ba24` fixed
them with observed failing tests followed by 12 passing release tests. The
actual successful publication exercised draft creation by ID, exact assets,
anchored download checksums, and tag-to-commit verification.

The writer-authorized publication marker is an intent check, not independent
approval. Repository immutable releases and required release reviewers are
not configured. DB content scanning is not exhaustive for arbitrary renamed
or nested payloads; release provenance also relies on reviewed build inputs,
explicit asset uploads, CArchive inspection and bundle self-test. API failure
during rollback can still require manual recovery. Wheel/EXE are unsigned;
Python 3.12 and onedir runtime have no separate acceptance result. Actions
reported automatic Node 24 migration warnings for the current action versions.

After publication, alpha.0 was checked again: target
`41497d682207c945a1fb54fcb8d4d9155cbdad7f`, the same two assets, and the same
known SHA-256 digests. [PR #1](https://github.com/andy846/world-Address-sorting-engine/pull/1)
remains OPEN and DRAFT with base `main`. No merge was performed.

## Measured performance and remaining gates

The completed synthetic 100k pipeline at clean `ec5301c`, rules
`2026-10-23.5`, measured 911.675 s, 109.7 records/sec, 56.8 MiB peak RSS,
62,057,316 checkpoint bytes and 25,944,558 export bytes. All rows reconcile:
96,364 MATCHED and 3,636 REVIEW_AMBIGUOUS. See `docs/benchmarks.md` for the
2k result and measurement scope; no larger-volume extrapolation is claimed.

Production remains NO-GO. Outstanding work is the independently verified
official Hongkong Post master, the k2 Simplified Chinese Hong Kong SAR alias
gap (`中华人民共和国香港特别行政区` currently resolves to CN), 1M/5M
measurements, onedir validation and clean offline Windows operator acceptance.
The downloaded EXE self-test covers startup/previews and refusal of unapproved
production classification; it is not full operator acceptance.
