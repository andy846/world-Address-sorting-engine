The operator confirmed manual testing passed on **25 October 2026**, accepted
this as the **sole current formal deployment**, and requested GitHub publication.
This release becomes **Latest**, superseding v0.1.0 as the active download while
preserving all older release/tag identities and assets as history.

`2026-10-25.country.7`. Release preparation updates only version identity,
release documentation and CI version checks. Country-code estimation remains
separate from the gated strict-postal classifier; no global accuracy or

## Included

- Offline English, Traditional Chinese, Simplified Chinese and mixed address
  analysis for CSV/TXT/XLSX, returning country codes and per-country counts.
- Original columns/order/duplicates preserved; detailed progress, summaries,
  attention-case inspection/export, cancellation and pinned resume identity.
- Windows workbench, application icon and persistent System/Light/Dark themes.

  incidental Lai/Yan aliases. The two official Hong Kong examples resolve HK
  with the optional ALS pair, without overriding assigned or explicit countries.
- Optional separately installed Hong Kong bilingual regional pack, disabled
  by default. Official bilingual aliases share address identity; Simplified
  aliases retain derivation provenance. Hashes and partial-source identity
  are verified and pinned for analysis/recovery.

## Install and use offline

Download `WorldAddressEngine.exe` and `SHA256SUMS.txt` from this release and
verify the executable hash. The application does not embed reference databases.

- Required global data: [preserved k2 GeoNames packs](https://github.com/andy846/world-Address-sorting-engine/releases/tag/geonames-packs-2026-10-22-k2),
  Compact 142,577,664 bytes or Extended 1,087,344,640 bytes. Follow
  [offline installation](../PACK_RELEASES_2026-10-23.md).
- Optional regional data: [ALS partial-source TEST pack](https://github.com/andy846/world-Address-sorting-engine/releases/tag/hk-als-partial-2026-10-23-r1),
  747,376,640-byte SQLite, 173,215 addresses. Keep manifest/audit/quarantine/
  attribution together. The 9,508 exclusions remain explicit; no source record
  was silently repaired. Follow [pack usage](../HK_REGIONAL_PACK.md).
- Select a global `pack.db`, input and output folder. Enable the regional pack
  only when intended, then choose its separate `pack.db`. Analysis is offline.
- Start new rules7 jobs; older checkpoints require the matching earlier build.
  Existing completed reports and original inputs are retained.

Reference data retain their original terms and attribution, separately from
the application license. No private input, row output or oracle is distributed.
