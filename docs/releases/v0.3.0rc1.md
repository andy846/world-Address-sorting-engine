# v0.3.0rc1 workflow candidate

Development branch: `feat/v0.3-workflow-zones`. This candidate requires new
manual acceptance. v0.2.0 remains the only formal deployment and GitHub Latest;
its published assets, tag and canonical local executable are preserved.

## Changes

Installed global Extended (Compact fallback) and Hong Kong packs are discovered
automatically. Hong Kong starts enabled. Missing or invalid references produce
an actionable status; the user can explicitly turn Hong Kong off. Manual paths
and appearance choices persist. No database download is performed.

Fresh GUI batches create a timestamped sibling output folder, with numbered
suffixes on collision. A custom location selects its parent folder. Existing
outputs remain intact; resume uses the selected run's original directory and
pinned references. CLI output arguments retain their exact-directory behavior.

The Single address lookup page accepts multiple lines, queries with Ctrl+Enter,
and shows country/name/status/reason/Zone/NOVSN. An independent persistent
background classifier supports queries during batch work. Edits invalidate
previous results and copy state. No address history is written.

The audited 235-country mapping adds literal `Zone_Code` and `NOVSN_Zone_Code`
to detail reports, summaries, case exports and lookup results. Mapping uses the
final business country code, preserving TP/XO/XK. CN is `CN - Airmail` / F,
HK is LOCAL / A, MO is `Macau - Surface` / M and TW is Taiwan / F.
CNS remains an excluded source audit row. These labels do not add a delivery
method setting or infer air/surface service.

## Compatibility and data identity

New report schema 2 preserves every original column before the three generated
columns, including original columns with colliding names. Diagnostics retain
their existing format. The manifest and state3 checkpoint pin the mapping
version, original PDF SHA256 and mapping resource SHA256. Unknown addresses
have all three generated fields blank; a known unmapped code is an error.

Completed legacy reports are read without rewriting, with blank zones.
Interrupted state2 runs must be resumed using v0.2.0; they are rejected without
mutation by this candidate. Country rules remain `2026-10-25.country.7`.

PDF source SHA256:
`41b84a0938c1ebe320514b29c567ceedcf9f9868e99f84f3387bb8899cf2f373`.
All 236 source rows were independently reconciled, with 235 active mappings.
The optional PDF parser is used only by the reproducible build-time importer.

## Measured performance and recovery

Measured with real Extended k2 + HK partial r1 on the local Windows machine,
with runtime/HEAD frozen and no concurrent builds or test suites. Benchmark
commit: `43e09bb045e18ca95dae930048c4f5f8d44d29f7`, clean tracked tree.
Runtime source fingerprint:
`6fa481354aa8a2c47af5c7fb995ecf53717d8d925e440ac2c12709d22f8c8b90`.

The workload preserves the 9,604-row input, adds 396 rows from four verified
public controls, then repeats the whole 10,000-row block 100 times. It has
**9,606 distinct classification keys**, not a million distinct addresses.
Source CSV: 132,199,207 bytes. No private rows or oracle are published.
